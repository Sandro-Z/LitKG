# 评审知识库 v1.0.0

这是可版本化的方法知识库，不是科学事实库。固定规则与每次运行的文献语料分开；新运行不继承上一运行的结论。优先级：用户确认的抽取规范/本体 → 本规则 → 标记为建议的领域惯例。冲突须显式记录，不能静默改标准。

## 知识库组织与检索

| 层 | 实际内容 | 使用条件 |
|---|---|---|
| K0 方法库 | 本文件的规则、标签、指标和门禁 | 每次加载核心定义；按问题查规则，不全量重复进每批提示词 |
| K1 契约库 | input-contract、request/report Schema、工具定义 | 接入与校验；不得把 schema 当事实证据 |
| K2 领域库 | 用户本体、关系释义、实体身份词典、单位表、能力问题；模板见 domain-profile.template.json | 只使用明确版本和依据；别名同名不等于身份等同 |
| K3 运行语料 | 当次实际使用的文献、补充材料、块索引与版本哈希 | 语义判断的原始证据；按声明检索并补读上下文 |
| K4 评测集 | 人工标注、争议裁决、失败与反例 | 离线评估；测试答案不进入待评 agent 的上下文 |

K3 不与跨项目旧语料混检；文献更新后按新哈希重审受影响声明。向量召回可以帮助 K3 定位，但遗漏审计必须按计划遍历文献区域，不能只审检索返回的区域。K2 缺失时不凭常识补成本体，也不必停止保真评审。

## 标签

| 标签 | 必要条件 | 不能这样使用 |
|---|---|---|
| SUPPORTED | 同一实体身份、关系、极性、强度、数量和必要上下文均有原文依据 | 仅主题相关、只看摘要或相似度高 |
| PARTIALLY_SUPPORTED | 核心关联有依据，但强度/粒度/限定条件/数值等有实质偏移 | 完全没有相关证据 |
| CONTRADICTED | 对齐上下文后，有原文明确表达不相容主张 | 文献未提到、不同实验结论不同 |
| UNSUPPORTED | 所需来源完整可读，已完成并记录约定检索，仍无支持 | 全世界为假、只检索一次无命中 |
| INSUFFICIENT_EVIDENCE | 文献缺失、区域未读、OCR 不可靠、实体或语义未消歧 | 为提高支持率而省去此项 |
| SOURCE_CONFLICT | 聚合声明所依据的来源在可比上下文中确有不相容证据，无法忠实压成一条 | 源明确限定的研究主张被另一研究推翻 |

证据角色：supports / contradicts / context。SUPPORTED、PARTIALLY_SUPPORTED 必须有 supports；CONTRADICTED 必须有 contradicts；SOURCE_CONFLICT 必须至少两个 doc_id 且兼有 supports/contradicts。UNSUPPORTED 的证据可为空，但 searched_blocks 与 search_notes 不得为空。INSUFFICIENT_EVIDENCE 要写缺口。

## 规则目录

| 规则 | 检查内容 | 典型动作 |
|---|---|---|
| ID-01 | 重复 ID、悬空主体/客体、错误引用 | 修正 ID 或映射，保留原始定位 |
| ENT-01 | 缩写、一词多义、同名实体、错并错拆 | 有身份依据才合并；先保留独立 ID |
| ENT-02 | 类型、规范名称、外部标识、节点事实属性 | 事实属性转原子声明审；标签元数据另记 |
| REL-01 | 关系含义、方向、粒度、domain/range | 只依据明确本体判硬约束 |
| POL-01 | 否定范围、无显著差异、证据不足 | “未显著”不能改成“无效”；“未证实”不是否定 |
| MOD-01 | 可能、推测、观察、关联、干预因果 | possible 不能升级 asserted；相关不能自动因果 |
| CTX-01 | 人群/物种/模型/条件/时间/方法/比较组 | 缺上下文使结论泛化时列实质错误 |
| NUM-01 | 数值、量纲、单位、比例分母、CI/误差、统计口径 | 保留原单位和转换式；先核表头脚注 |
| PROV-01 | 来源版本、证据片段、页码、作者/研究归属 | 区分 PDF 物理页和印刷页；不猜页码 |
| CON-01 | 对齐上下文后的来源冲突 | 保留来源特定声明，不自动多数票合并 |
| DUP-01 | 语义完全相同的条目、重复文献版本 | 合并建议保留全部证据；重复不是独立验证 |
| MISS-01 | 抽取范围内，有证据且图中缺少可对齐声明的候选 | 先冻结独立候选再匹配，查别名与重化事件 |
| ONT-01 | 用户本体/约束中明确规定的规则 | 无本体仅给建议；不把 OWL domain 推理当数据库约束 |

## 严重度与置信等级

- blocker：破坏可解析性或身份定位，如 ID 冲突导致无法唯一寻址、严重悬空引用；以及用户明确指定的阻断规则。
- high：改变核心查询结论的错误实体、反向关系、否定反转、相关升级因果、数量级错误、错归研究。必须说明影响，不能按规则名机械定级。
- medium：改变部分查询答案的限定条件缺失、类型/单位/来源映射问题或确定的范围内遗漏。
- low：对当前查询影响有限的格式、规范化、可恢复引用或重复提示。
- info：改进建议、可读性或方法局限。

confidence 是证据可判定程度：high=直接、清晰、上下文完整；medium=需要清晰可解释的跨句消歧；low=仍有歧义，通常保留 hypothesis/INSUFFICIENT_EVIDENCE。不是模型概率，不与严重度相乘造总分。

## 指标

设规范图谱声明数 N，唯一已审数 R，各终态数量 S/P/C/U/I/X。

- 声明覆盖率 = R/N；N=0 时 null，不能 100%。
- 已审严格支持率 = S/R；R=0 时 null。分母包括所有未定标签，名称不能简称全图精确率。
- 已审未定率 = (I+X)/R。未定与未审分开；R 只能包含完成判定的声明。
- 块覆盖 = 计划块中审过的唯一块数/全部计划块；文本读过不代表图像或脚注已核验，未审区域单列。fidelity 与 omission 的用途覆盖分别可从矩阵追溯。
- 独立候选命中率 = matched/(matched+misrepresented+missing)，只在抽取范围已知时报告；ambiguous 单列，out_of_scope 排除。matched 是忠实等价表示；misrepresented 是已有可对齐声明但表达错误，关联已有 claim finding，不重复作为漏抽问题；missing 仅指缺少可对齐声明。称“候选集命中率”，不能称完整召回率。
- 人工金标准评测另建任务：固定语料、范围、实体对齐和上下文等价关系后计算 TP/FP/FN；不得拿评审模型自己生成的候选当金标准。

不默认加权总分，不用一个分数覆盖 blocker。抽样报告仅适用于样本；若需总体估计另行设计抽样、权重、置信区间，不能把高风险定向样本直接外推。

## 门禁

先判已确认错误：blocker 为 FAIL，high/medium 为 NEEDS_REVISION。无上述错误但有未审、未知范围、不可读材料、未定结论、未解决假设、候选歧义或未核区域为 INCOMPLETE。其余 PASS。来源冲突本身不自动意味着抽取有错；若错误地聚合或抹除上下文，另立 confirmed finding。

## 外部标准的使用边界

- [SHACL 2017 Recommendation](https://www.w3.org/TR/2017/REC-shacl-20170720/)：针对 RDF 图与显式 shape 条件的验证，适合作结构扩展，不替代文献语义评审。
- [PROV-O 2013 Recommendation](https://www.w3.org/TR/2013/REC-prov-o-20130430/)：可将文献/图谱声明映为 Entity、抽取/评审映为 Activity，并用 wasDerivedFrom 表达溯源。这里只建议映射，不声称规范 JSON 等于 PROV-O 合规输出。
