METHOD & LIMITS

评分方法

透明的场景加权

高 / 中 / 低对应权重 3 / 2 / 1，按你的七类应用场景分别设置领域专门化、粒度、完整性和正确性。本体合规权重为正确性权重的一半，覆盖代理权重为完整性权重的一半。综合分为各维度 0–100 分的加权均值。

正确性使用已审严格支持率（SUPPORTED / 全部已审，包括未定），部分支持单列。完整性使用范围内独立候选命中率 matched / (matched + misrepresented + missing)。候选在看图谱前从原文提取并冻结；它们不是人工金标准，不能称召回率或 F1。

领域专门化检查身份、类型及术语的精细程度；粒度检查必要限定条件、极性、模态和数值的保留。LLM 给分须有原文锚点。覆盖代理汇总名词短语表示、候选谓词保留、否定保留和关系数量比例；异常仅是复查线索。

缺失维度不会补零或自动判为合格。暂定分仅使用已测权重，并显示权重覆盖率。未审、未定、模型失败或上下文超限时保留未完成状态，同时展示已经取得证据的维度分和缺项原因。严重结构问题直接阻断适用性。

适用性判据

场景的高 / 中 / 低要求分别使用 80 / 65 / 50 分作为工程门槛。任一主要维度不达标判为“不适用”；没有已知不达标但评审不完整时为“待验证”。门槛与权重是可解释的产品规则，未经过外部效度校准。

人工评审

所有 claim 等概率无放回抽取；只按图谱整体不确定性调节样本数量，不改变单条抽中概率。每轮样本保存后固定，可新增轮次。每次提交保留评审员、轮次、时间与备注。支持率与 Wilson 95% 区间单独展示，未定不并入已判定分母，人工结果影响正确性维度：默认人工权重30%×已判定唯一claim数/所有轮次抽样claim并集数，其他维度不被人工抽查替代。同一人每条claim跨轮只取最新意见，不同人意见等权，随后按claim等权平均；改判历史均保留。

证据边界

忠实表达原文并不证明文献结论在现实中正确。图像、复杂表格和未提供附件不自动视为已核验。LitKG 保存块默认标为部分来源；完整性需要补齐原文并明确抽取范围。无来源可导入、做约束检查和抽样，但不会生成已经通过的证据评分。
